This project applies core probability distribution concepts to a real-world sports betting scenario involving a multi-game series between the Boston Red Sox and New York Yankees. Building on the module’s foundation—covering discrete and continuous distributions, goodness-of-fit tests, and random number generation—the analysis uses these tools to model game outcomes, evaluate expected returns, and assess the risk associated with a betting strategy. The project demonstrates the application of Bernoulli trials, expected value calculations, confidence intervals, and chi-square tests within a structured analytical workflow that reflects the module’s learning objectives.

Using both Excel and R, the project evaluates three scenarios: a three-game series with Boston hosting first, a three-game series with New York hosting first, and a five-game alternating home-field series. For each scenario, I computed series win probabilities, constructed the probability distribution for net winnings, simulated 10,000 random outcomes to estimate expected returns, and validated results with chi-square goodness-of-fit tests. The analysis shows that home-field advantage significantly affects series outcomes and betting profitability, with higher expected net wins when the Red Sox host the opening game—especially in the five-game series. The findings highlight how probability theory can inform decision-making under uncertainty and illustrate the importance of modeling, simulation, and statistical validation in evaluating real-life betting strategies.
