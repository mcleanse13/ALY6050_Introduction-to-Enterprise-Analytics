This project demonstrates the application of Monte Carlo simulation and probability distributions to perform a benefit-cost analysis for two competing dam projects. Building on the module’s focus on random number generation and simulation techniques, I generated 10,000 benefit-cost ratio simulations for each dam and constructed graphical and tabular frequency distributions to analyze the outcomes. Using the triangular probability distribution as a theoretical model, the project applied chi-squared goodness-of-fit tests to validate the alignment between observed and expected values, ensuring that the simulation accurately represented the underlying benefit-cost relationships. These analyses allowed for a rigorous, data-driven approach to evaluating the potential success of each project.

Based on the results of the simulations and statistical tests, the second dam consistently showed slightly higher benefit-cost ratios compared to the first dam, with stronger alignment between theoretical and observed distributions. The analysis considered skewness, expected values, and goodness-of-fit outcomes to determine which project was more advantageous. Ultimately, the data-driven recommendation is to select the second dam for the upcoming project, as its expected benefits outweigh the associated costs, and its probability distributions indicate a higher likelihood of favorable outcomes. This project highlights the power of simulation and statistical modeling in making informed business decisions under uncertainty.
