This project focuses on forecasting the future values of Apple Inc. (AAPL) and Honeywell International Inc. (HON) stock prices over a one-year period of 252 market days, applying the methodologies learned in the module including linear algebra, regression analysis, and forecasting techniques. Short-term forecasting was conducted using exponential smoothing with multiple alpha values, while long-term forecasting applied 3-period weighted averages to capture stock trends and patterns over time. Additionally, simple linear regression and residual analysis were employed to predict stock prices and verify the appropriateness of regression models. Forecast accuracy was assessed using metrics such as the mean absolute percentage error (MAPE), allowing for evaluation of how closely the forecasts matched actual stock performance.

The project culminates in an investment allocation analysis, where the insights from short-term and long-term forecasting, as well as regression results, inform the recommended portfolio distribution between Apple and Honeywell stocks. While Honeywell showed higher short-term forecasting accuracy, Apple demonstrated more stability in long-term trends, leading to a suggested allocation of 55% to Apple and 45% to Honeywell. Overall, this project highlights how a combination of forecasting methodologies, statistical modeling, and error analysis can guide data-driven investment decisions and provide actionable insights into the potential performance of different assets over time.
